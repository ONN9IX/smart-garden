# Smart Garden — Codex CLI уже на Windows: безопасное подключение к Cloud

**Текущий статус (PR #205):** инфраструктурная интеграция GitHub Actions протестирована.
Выполнение Issues, изменение кода, Git push, Telegram и merge остаются **отключены**.
Файлы этой инструкции и Windows preflight **не запускают** Codex-задания.

## Ключевое различие

- **Codex CLI на ПК:** выполняет локальные задачи, только пока доступен ПК.
- **Codex Cloud:** отдельные задания выполняются на управляемых OpenAI серверах и
  продолжают работать после выключения домашнего компьютера (если функция доступна
  твоему аккаунту и региону). Используются лимиты ChatGPT/Codex, не отдельный
  provider API key. Создание/публикация Cloud environment и GitHub OAuth требуют
  личного однократного подтверждения.
- **GitHub Actions observer:** читает очереди и CI без прав на запись. Он **не вызывает** Codex Cloud и не может самостоятельно подавать задания на Cloud.
  Установка CLI на Windows этого ограничения не отменяет.

## Windows — проверка без изменений продукта

В *доверенной копии репозитория* (или проверенном архиве PR #205) открой PowerShell:

```powershell
powershell.exe -NoProfile -File .\automation\windows\check-codex.ps1 -CheckCloud
```

Или запусти двойным щелчком `automation\windows\check-codex.cmd`.

Скрипт выполняет только `codex --version`, `codex login status`,
`codex cloud list --json --limit 1` и публичный GET GitHub main. Результаты
авторизации и список Cloud задач **не печатаются**. Токены не передаются в
ChatGPT, Actions или репозиторий. Нет прав администратора, регистрации Task
Scheduler и изменений локального кода. Код выхода 0 означает, что проверки
доступа прошли, **а не** что Cloud окружение опубликовано или задачи автоматически
стартуют.

Если команда `codex` отсутствует, установленное приложение может не включать
Codex CLI в PATH. Если `codex login status` не прошёл, авторизуйся через обычный
`codex login` в собственном терминале; не отправляй сюда код входа или токены.

## Единственная ручная настройка Cloud (без VPS и карты)

1. Открой раздел **Codex** в ChatGPT (веб или десктоп) и проверь доступность
   **Codex Cloud**. Не обходи региональные/плановые ограничения.
2. Подключи свой GitHub аккаунт, разрешив доступ к `ONN9IX/smart-garden`;
   если репозиторий уже подключён к ChatGPT, убедись, что он также виден именно
   в Codex Cloud.
3. Создай облачное окружение для репозитория и **опубликуй** его по инструкции
   интерфейса. Не загружай реальные персональные данные и секреты проекта.
4. Только для read-only smoke-test запусти одну задачу Cloud в режиме анализа:
   «Прочитай AGENTS.md и automation/CODEX-CLOUD.md, назови текущие gates,
   не изменяй ни один файл, не создавай ветку/PR и не запускай разработку».
5. Убедись, что эта конкретная задача завершилась в облаке, даже если компьютер
   был выключен. Из результатов можно передать URL задания без секретов.

Эта одноразовая настройка не выполняется автоматически через GitHub connector.
После опубликования окружения можно подготовить отдельно утверждённую цепочку
для новых Issues. Самостоятельный cloud-dispatch **пока не реализован**:
официальный Codex GitHub Action требует API-ключ, а Plus OAuth нельзя переносить
на GitHub-hosted runner ради экономии. Новые продуктовые задачи не запускаем.

## Безопасные границы для будущих задач

Только Master Chat-approved Issue, точный `BASE-SHA`, `WRITE-SET`, синтетические
данные, одна ветка и один PR, обязательная CI, отдельное ревью и явное решение
перед merge. Никаких замороженных Stage, auth/RBAC, миграций БД или 152-ФЗ
изменений без нового согласованного Issue. Запрещено выгружать OAuth/секреты
в GitHub Actions и использовать непрозрачные сторонние бесплатные AI сервисы.
